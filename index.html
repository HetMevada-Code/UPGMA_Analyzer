08 UPGMA Formula Sheet & Concepts

Keep this section open while stepping through the analysis.

p-distance

d(A,B) = differences / sequence length

For aligned DNA sequences, every position is compared directly.

Cluster distance

d(X,Y) = Σ d(i,j) / (|X| × |Y|)

Average all sequence-to-sequence distances between two clusters.

Weighted update

d(X∪Y,Z) = [|X|·d(X,Z) + |Y|·d(Y,Z)] / (|X|+|Y|)

This is the efficient UPGMA arithmetic-mean update.

Node height

h = d(X,Y) / 2

The merge distance is twice the height above the leaves under UPGMA.

Branch length

branch = parent height − child height

Leaves start at height 0.

UPGMA assumption

Molecular-clock assumption UPGMA assumes approximately equal evolutionary rates among lineages, producing an ultrametric/rooted interpretation. Strongly unequal rates can make UPGMA misleading.
